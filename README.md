# Mphethi Enterprise & Mphethi Logistics Website

## WEDES020POE -- Part 2 Submission

### 1. Project Overview

This project is a responsive business website developed for **Mphethi
Enterprise & Mphethi Logistics**. The website provides visitors with
information about the business, its services, gallery content and
contact details.

The website was developed using HTML5, CSS3 and JavaScript, with a focus
on semantic structure, responsive design, accessibility, usability and a
consistent visual style.

### 2. Target Audience

The target audience includes: - Potential customers looking for
logistics and business services. - Existing customers who need company
information and contact details. - Individuals or organisations
interested in Mphethi Enterprise & Mphethi Logistics services. -
Business partners and other stakeholders.

### 3. Project Goals

The main goals are to: - Present the business professionally online. -
Clearly explain the services offered. - Make contact information easy to
find. - Provide a responsive experience on desktop, tablet and mobile
devices. - Use a clear and consistent navigation structure.

### 4. Technologies Used

-   **HTML5** -- page structure and semantic content.
-   **CSS3** -- layout, typography, colours, responsive design and
    visual styling.
-   **JavaScript** -- mobile navigation and contact-form validation.
-   **SVG** -- responsive image assets.
-   **Git/GitHub** -- version control and project submission.

### 5. Website Pages

-   `index.html` -- Home page
-   `about.html` -- About the business
-   `services.html` -- Services
-   `gallery.html` -- Gallery
-   `contact.html` -- Contact page

### 6. Features Implemented

-   Semantic HTML5 structure including header, navigation, main content
    and footer.
-   External stylesheet linked to all pages.
-   CSS reset/base styling for consistency.
-   Consistent typography and spacing.
-   CSS Grid and Flexbox layouts.
-   Desktop, tablet and mobile responsive breakpoints.
-   Relative units such as `rem`, `em` and `%`.
-   Responsive images using `picture`, `srcset` and `sizes`.
-   Navigation hover, focus and active states.
-   Mobile navigation menu controlled with JavaScript.
-   Contact form validation.
-   Basic SEO metadata and descriptive page titles.
-   Keyboard-friendly focus states.

### 9. Responsive Design

The website is designed to adapt to different screen sizes.

Suggested testing sizes: - **Desktop:** 1440px wide - **Tablet:** 768px
wide - **Mobile:** 375px wide

The responsive CSS changes the layout from multi-column desktop sections
to simpler single-column mobile sections where required. Navigation also
changes to a mobile-friendly menu.
